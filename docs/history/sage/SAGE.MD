What is sage?

Sage is an Real World Operating System with non determinitic LLM as core.

Sage is a open source version of that. 

| Layer | Question it answers | Typical components |
|---|---|---|
| **1. Observation and interaction** | What can the system perceive, and how do we communicate? | Chat, voice, cameras, screens, application events |
| **2. State and memory** | What does it know about the current situation and past? | Task state, event history, user preferences, retrieved documents |
| **3. Models** | What can it infer, generate, or predict? | Language models, visual models, speech models, predictive world models |
| **4. Decision and control** | What should happen next? | Plans, workflows, action selection, verification, stopping rules |
| **5. Runtime and authority** | When does work run, and what may it do? | Scheduling, recovery, isolation, permissions, credentials |
| **6. Actions and integrations** | How does it change the world? | APIs, MCP tools, browsers, terminals, device controls |
